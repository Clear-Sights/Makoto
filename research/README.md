# Makoto research records

This branch holds the rules, predictions, harnesses, raw data and results of Makoto's measured rounds. `main` holds only the plugin. Records of rounds 7 to 13 and of 6.0.0 and 6.1.0 are in Clear-Sights/Tiller-from-the-Ashes, `research/raw/makoto_*`.

Each round's rules and predictions are committed before its code and runs, and are never edited after; changes are `AMEND` files.
